Tus archivos siguen siendo tuyos.

SharkDrive usa la API oficial MTProto de Telegram. Tus carpetas se guardan como canales privados y tus archivos como mensajes dentro de tu propia cuenta.

La app añade la experiencia que esperas de un drive moderno: búsquedas, vistas, previsualizaciones, organización y automatización, sin convertir cada tarea simple en un panel técnico.

Preguntas frecuentes

Lo esencial,
sin letra pequeña.

¿Dónde se guardan mis archivos?+

En tu propia cuenta de Telegram. SharkDrive usa Saved Messages y canales privados para ofrecer una experiencia similar a un drive de escritorio.

¿SharkDrive tiene un costo mensual?+

No. SharkDrive es un proyecto open source. Aplican los límites normales de Telegram, incluido el tamaño máximo permitido por archivo.

¿Tengo que cifrar todos mis archivos?+

No. El cifrado es opcional. Puedes activarlo para una carpeta o elegirlo cuando necesites proteger contenido sensible.

¿Puedo usarlo sin conocimientos técnicos?+

Sí. La interfaz principal está pensada para subir, encontrar y descargar archivos sin exponer opciones avanzadas hasta que las necesites.

¿Dónde puedo reportar un problema?+

Puedes abrir un issue en el repositorio público de GitHub para describir el error o proponer una mejora.
